# Explore iteration screenshots — 14 November 2026

Captured on the connected Samsung SM-S928B (1440 × 3120) from the arm64 build of `feat/search-tab-redesign` (shipped in v0.6.5-alpha), installed over the existing app (existing watchlist/cache preserved). These are device screenshots, not mockups.

| Image | What it shows |
| --- | --- |
| [01-explore-feed.png](01-explore-feed.png) | Explore tab after the redesign: Watchlist-style blue banner, Search/“Searching…” pill, cross-store field, department rail, watchlist relevance line and grouped comparison rows. Watchlist-only items are filtered out unless another store is cheaper. |
| [02-search-starting.png](02-search-starting.png) | First-search feedback: the banner shows “Searching…”, the results area says matches will appear as stores respond, and the animated progress card starts checking 20 stores instead of showing an empty result. |
| [03-search-progress.png](03-search-progress.png) | Search progress while stores stream in: animated bar, per-store checking/ready/empty pills, cached results visible and the grouped Noon + Carrefour AirPods row at the top. |
| [04-grouped-results.png](04-grouped-results.png) | Completed search results: 46 grouped products across 5 stores, the Noon + Carrefour AirPods row showing “Lowest at Noon · 2 stores · Save AED 150”, and no Show more/Load more buttons. |
| [05-compare-lowest-first.png](05-compare-lowest-first.png) | Compare sheet: store offers sorted lowest price first, “Lowest price first” caption, best comparable offer highlighted, tracked-price saving and per-store titles/prices/check age. |
| [06-filters.png](06-filters.png) | Filter sheet: stores with grouped counts, brands and maximum price, matching the Watchlist filter interaction. |
| [07-auto-load-footer.png](07-auto-load-footer.png) | Bottom-of-list automatic continuation: a compact “Checking more stores…” row replaces the old Show more/Load more buttons. |

Behaviour and limits are documented in [the Search tab review](../../search-tab-review.md#9-follow-up-iteration-explore-experience-14-november-2026) and [design QA](../../../design-qa.md#explore-experience-iteration--device-verification-14-november-2026).
